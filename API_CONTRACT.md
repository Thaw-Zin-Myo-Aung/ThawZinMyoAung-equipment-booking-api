# API Contract — Campus Equipment Booking API

**Base URL:** `http://localhost:8787/api`
All request and response bodies are JSON (`Content-Type: application/json`).

## Assumptions

1. Times are ISO-8601 date-times. They are normalised to UTC (`YYYY-MM-DDTHH:mm:ss.sssZ`) before storing, so the API always returns the `Z` form.
2. Booking intervals are **half-open** `[startAt, endAt)`. A booking ending at 11:00 does **not** conflict with one starting at 11:00 (back-to-back bookings are allowed).
3. Two bookings conflict only when they are for the **same equipment** and `existing.startAt < new.endAt AND existing.endAt > new.startAt`.
4. Booking `id` is generated by the server (UUID). Clients cannot choose it.
5. `PATCH` is a partial update: fields that are not sent keep their current value. The merged result is validated with the same rules as `POST`, and the overlap check ignores the booking being updated.
6. Equipment is seed data only (read-only via the API). No authentication is required (out of scope for this lab).

## Equipment

### `GET /equipment` → `200`

```json
[
  { "id": "eq-1", "name": "Projector A", "location": "Building 1" },
  { "id": "eq-2", "name": "Camera Canon EOS", "location": "Media Lab, Building 2" }
]
```

## Bookings

| Method | Path | Success | Errors |
|---|---|---:|---|
| `GET` | `/bookings` | 200 | — |
| `GET` | `/bookings/:id` | 200 | 404 |
| `POST` | `/bookings` | 201 | 400, 404, 409 |
| `PATCH` | `/bookings/:id` | 200 | 400, 404, 409 |
| `DELETE` | `/bookings/:id` | 204 (empty body) | 404 |

### Request body (POST, PATCH)

```json
{
  "equipmentId": "eq-1",
  "borrowerName": "Somchai Jaidee",
  "startAt": "2026-10-20T09:00:00.000Z",
  "endAt": "2026-10-20T11:00:00.000Z",
  "purpose": "Class presentation"
}
```

POST: all five fields are required. PATCH: send any subset.

### Booking response

```json
{
  "id": "38b944dd-ca98-4a87-abe9-d979658ac96a",
  "equipmentId": "eq-1",
  "borrowerName": "Somchai Jaidee",
  "startAt": "2026-10-20T09:00:00.000Z",
  "endAt": "2026-10-20T11:00:00.000Z",
  "purpose": "Class presentation",
  "createdAt": "2026-10-06T06:42:13.391Z"
}
```

## Errors

Every error is JSON: `{ "error": "message" }`

| Status | When | Why this code |
|---:|---|---|
| 400 | Missing field, invalid date, `startAt >= endAt` | The client sent data that is invalid on its own; it must fix the request. |
| 404 | Booking `:id` not found; `equipmentId` does not exist | The resource the request refers to does not exist. |
| 409 | Time overlaps another booking of the same equipment | The request is valid, but it conflicts with the current state of the server. |
